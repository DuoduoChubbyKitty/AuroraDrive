## 各区块设计意图

### Hero —— 用「管线示意」代替氛围插画
右侧不是装饰插画，而是一块 `aurora-engine · runtime` 面板：捕获 15fps / 推理 15Hz / 注入按键事件三段竖排，各带状态灯。**因为这个项目的说服力来自"它是真在跑的"，不是来自图好看。**AI 插画另辟独立区块，与文字是兄弟容器而非叠加层——避免压字。

极光渐变只用在标题末词「踩油门」三字，全屏强调色不超过三处。

### 功能网格 —— 每张卡都带源码行号
8 张卡，每张底部是 `DegradeStateMachine.swift:5-9` 这样的行号引用。这不是装饰，是可验证性：**读者可以立刻自己去核**。每 5 张插一张横向大卡，打破「一图标一标题一行字」的模板感。

### 数据统计 —— 等宽 tabular-nums
6 个数字全部用等宽字体 + `tabular-nums`，单位小一号降为次要层级。读起来像仪表读数而非营销数字。滚动进入视口时按 `cubic-bezier(0.16,1,0.3,1)` 计数 1200ms，小数位保留原数（1.91 不会滚成 2）。

### 快速开始 —— 命令逐字照抄 README
`git clone` / `cd` / `./run.sh` / `./run.sh --status` 全部原样保留，不美化。代码窗有语法高亮（命令蓝、注释灰）、行号、复制按钮，复制成功显示「✓ 已复制」并保持 1600ms，屏幕阅读器通过 `aria-live` 同步。

### 三档降级 —— 档位用「能力格数」而非红黄绿
档 1 满格、档 2 三分之二、档 3 三分之一，颜色分别是青绿 / 靛紫 / **钢灰**。

**规则档刻意不用红色** —— 它是系统正常工作状态（"更笨但更稳"），不是故障。红与橙只留给真正的异常：协议版本不匹配、权限缺失、坐标定位 lost。

### 定价 —— 三档全 ¥0
按项目实际性质（GPL-3.0 全免费）改为「全部免费，没有付费墙」。三档价格均为 ¥0，差别只在社区参与度与协作深度，对比表加了「价格」一行明示。对外文案不出现任何售卖话术。

### FAQ —— 单开手风琴
10 条，问的是真问题（会不会封号 / 能不能自己跑 / 模型从哪来 / 插帧为何不进决策链路 / 会向外发数据吗 / 能商用吗）。答案宁可写「我们没把握」也不粉饰。展开动画 260ms `cubic-bezier(0.4,0,0.2,1)`，带 `aria-expanded` / `aria-controls`。

### 团队 —— 角色位而非假人设
按贡献方向呈现 5 个角色（核心维护者 / 端到端主驾 / 工具链与 Agent / 地图与定位 / 采集与显示），头像用 CSS 渐变 + 首字母几何块，不虚构人名与照片。

### 场景 —— 用「谁在用、关心什么」替代假评价
未广泛发布的项目不编造具体人名与星级评分。改为三类典型场景 + 每类最关心的一件事（端到端研究者 → 三档降级；视觉工程开发者 → 双进程共享内存；玩家 → 地图与任务 OCR）。

### 联系表单 —— 为接后端预留
称呼 / 邮箱 / 主题 / 内容四字段，失焦校验、错误聚焦第一个出错字段、`aria-invalid` + `aria-describedby` 关联。**后端尚未接入**，文案如实写「表单后端接入中，当前为前端模拟提交」——不伪装成发送成功，也不断言"不收集数据"（那会挡住后期接后端）。

### 页脚 —— 合规信息固定位置
GPL-3.0-or-later 许可说明、MaaNTE 的 AGPL-3.0 传染性说明（源码不随本仓库分发）、游戏自动化免责声明原文，各有固定区块与固定层级——这是专业度的证明，不是减分项。

## 实现要点

### 页面过渡（重点）
出场 200ms（`cubic-bezier(0.5,0,0.9,0.5)`，上浮淡出）→ 进场 360ms（`cubic-bezier(0.16,1,0.3,1)`，下方 12px 淡入上浮），合计 560ms。**出场短、进场长是刻意的**：出场快给响应感，进场慢给落位感。

六条防闪烁硬规则全部落实：
1. `AnimatePresence mode="wait"` —— 同一时刻只有一版 DOM，不出现两层半透明重影
2. `initial={false}` —— 首屏不做入场动画（否则刷新时整页上飘）
3. `initial` 上绝不设 `scale` —— 只用 `opacity` + `translateY`，避免亚像素抖动
4. 进场位移 ≤16px —— 超过会读作"页面飞进来"
5. `scrollRestoration='manual'` + `scrollTo({behavior:'instant'})` —— 不用 smooth，否则旧页淡出时缓慢上滑
6. 页面根背景色恒定 `var(--bg-base)` —— 退场最后一帧与进场第一帧之间不闪白

`Navbar` / `Footer` 放在 `PageTransition` **之外**，否则它们跟着页面一起淡出淡入会破坏站点连续性。

主题切换用 View Transitions API 做圆形扩散（clip-path 从按钮中心扩散），不支持时退化为直接切换。`index.html` 内联脚本在首次绘制前定好 `data-theme`，杜绝深色模式白闪。

### 滚动渐入
`IntersectionObserver`，threshold 0.15，rootMargin `0px 0px -10% 0px`，`once` 触发后不再重播。位移 20px、时长 640ms、同级错峰 70ms 且**总延迟封顶 280ms**（防止长列表末尾等太久）。

### 深色模式
`data-theme` 属性 + class 双写，localStorage 持久化 `aurora-theme`，系统偏好兜底。深浅两套配色 184 项 WCAG 对比度实测 0 失败（`contrast-check.py` 可复跑）。

### 无障碍
语义标签齐全（单个 h1、main/nav/footer/header 到位）、`:focus-visible` 全局焦点环、手风琴与菜单带 `aria-expanded` / `aria-controls`、复制反馈走 `aria-live`、图片全有 alt（装饰图为 `alt=""`）、移动端触控目标 ≥44px、`prefers-reduced-motion` 时取消位移与无限循环动效。

### AI 配图
9 张统一风格：深底 + 青绿→靛紫极光缎带 + 1px 几何线 + 数据流意象，禁文字/人脸/游戏画面。已裁水印、缩至 1600px 宽、JPEG quality=82，总体积 23 MB → 1.9 MB。
