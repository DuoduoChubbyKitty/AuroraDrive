## 五、三个关键口径警示（避免误读数字）

1. **「污染折」与「干净折」不可混用**：
   `epoch_15` 训练了 11 个片段中的 10 个。凡在这 10 个片段上测得的数字（如历史上的 0.7764、0.7385）
   都含训练泄漏，**只能作同一批折上的组内相对比较**，不能当作泛化能力。
   干净口径只认 `最终7折缓存_ep6/` 的 0.6069。

2. **`seg_d` 不是独立片段**：经哈希核对（160/160 帧逐字节相同），它是 `clip_20261107_110525` 的裁剪。
   该片段**基线与候选都未训练过**（`epoch_15.pt` 元数据 `val_clips` 为证），故 5/20→0/0 是**公平相对比较**；
   但它参与了两者的选模，**绝对数值偏乐观** → 门槛1 的最终验收需**新录片段**复验。

3. **fp16 与 INT4 不可跨后端直接比较**：同一权重在 110525 上 fp16 → INT4 的 vMacro 差 **0.0145**
   （0.7385 → 0.7240）。故「候选 vs 基线」必须**同后端**：当前同后端（均 INT4）结果为
   **基线 0.7452 vs 候选 0.7240（−0.0212）**，可分别用 `基线缓存_110525/` 与 `候选INT4缓存_110525/` 复算。
   报告 §4.1 的 7 折 **0.6069 来自 fp16**（`ft_scratch_long` 无 INT4 包，其 INT4 值未实测）。
