## 1. 代码核实：开关真实存在

`MissionConsole.swift:3156-3161`（逐字）：
```swift
BankSwitch(key: "第三视角", badge: state.recordThirdPerson ? "TPV" : "FPV",
           on: state.recordThirdPerson,
           detail: state.recordThirdPerson
               ? "开启 · 录第三人称（追尾）"
               : "关闭 · 录第一人称",
           toggle: { state.recordThirdPerson.toggle() })
```

**核实项**：
- 开关**不是注释**（在 `BankSwitch(...)` 构造器内，会渲染）✅
- 绑定 `state.recordThirdPerson`（`on:` + `toggle:`）✅
- toggle 逻辑 `.toggle()` 正确 ✅
- badge 显示 `TPV`/`FPV`（实时反映状态）✅

**上下文**：此开关在录制面板的 `BankSwitch` 组里，与「专家模式」「字形模式」并列（`:3140-3162`）。

## 2. 链路核实：逐段无断点

### 2.1 UI toggle → recordThirdPerson
`MissionConsole.swift:3161`：`toggle: { state.recordThirdPerson.toggle() }`
⟹ 拨开关直接写 `DriveState.recordThirdPerson` ✅

### 2.2 recordThirdPerson → recordPerspective
`AuroraDriveApp.swift:4285-4289`：
```swift
var recordThirdPerson = false
var recordPerspective: String {
    recordThirdPerson ? "third" : "first"
}
```
⟹ 计算属性自动跟随 ✅

### 2.3 recordPerspective → socket 命令（引擎模式）
`AuroraDriveApp.swift:4986-4993`（`isRecording.didSet`）：
```swift
EngineClient.shared.sendCommand("record", extra: [
    "on": isRecording,
    "glyph": glyphMode,
    "expert": expertMode,
    "perspective": recordPerspective,   // ← 视角随命令下发
])
```
⟹ 引擎模式：视角通过 socket `"perspective"` 字段下发 ✅

### 2.4 recordPerspective → RecordEngine.start（UI 直跑模式）
`AuroraDriveApp.swift:5002`：
```swift
recordEngine.start(perspective: recordPerspective)
```
⟹ UI 直跑模式：直接传给录制引擎 ✅

### 2.5 引擎侧接收
`EngineMain.swift:1236-1237`：
```swift
let recPerspective = RecordEngine.normalizePerspective(
    (obj["perspective"] as? String) ?? "first")
```
`:1251`：`st.recordThirdPerson = (recPerspective == "third")`
`:1255`：`st.recordEngine.start(perspective: recPerspective)`
⟹ 引擎读 `"perspective"` 字段 → 归一化 → 同步 state + 传给 RecordEngine ✅

### 2.6 RecordEngine 写 view.txt
`RecordEngine.swift:202-241`：`normalizePerspective` → `viewLabel = "FPV"/"TPV"` → `write(view.txt)`
⟹ 最终落盘 `view.txt` = `TPV` 或 `FPV` ✅

**结论：链路 6 段全部通，无断点。**

## 3. 实机验证（决定性证据）

### 3.1 测试环境
```
$ AURORA_DIGEST=1 ./.build/scratch/release/AuroraDrive --engine
[ENGINE] 启动 --engine 模式 pid=65886
[ENGINE] TCC 自检 ax=true screen=true
[ENGINE] socket 监听就绪
```

### 3.2 正向验证：perspective=third → TPV

**发送命令**：
```python
payload = {"type":"record","on":True,"expert":True,"perspective":"third"}
# [sent] {"type": "record", "on": true, "expert": true, "perspective": "third"}
```

**引擎日志**（`/tmp/v3_engine.log`）：
```
[23:02:07.444] [ENGINE] 录制开始：字模=false 专家=true 视角=third(TPV) 会话=clip_20261010_230207
```

**落盘验证**：
```
$ cat data/raw_clips/clip_20261010_230207/view.txt
TPV
```

⟹ ✅ **视角=third(TPV)，view.txt=TPV**

### 3.3 反证：perspective=first → FPV

**发送命令**：
```python
payload = {"type":"record","on":True,"expert":True,"perspective":"first"}
# [sent] {"type": "record", "on": true, "expert": true, "perspective": "first"}
```

**引擎日志**：
```
[23:02:44.528] [ENGINE] 录制开始：字模=false 专家=true 视角=first(FPV) 会话=clip_20261010_230244
```

**落盘验证**：
```
$ cat data/raw_clips/clip_20261010_230244/view.txt
FPV
```

⟹ ✅ **视角=first(FPV)，view.txt=FPV**

### 3.4 对照表（证明开关真的在切换）

| clip | 命令 perspective | 引擎日志 | view.txt | 帧数 |
|---|---|---|---|---|
| `clip_20261010_230207` | `"third"` | `视角=third(TPV)` | **TPV** | 970 |
| `clip_20261010_230244` | `"first"` | `视角=first(FPV)` | **FPV** | 105 |

**两个 clip 的 view.txt 不同 → 开关真的在切换（不是硬编码）** ✅
