### 断言 4：`_safe_float` 语义（最关键的基础契约）

```
✅ _safe_float(None)  → None
✅ _safe_float('')    → None
✅ _safe_float('  ')  → None
✅ _safe_float('nan') → None
✅ _safe_float('NULL')→ None
✅ _safe_float('120.0')→ 120.0
✅ _safe_float('abc') → None
✅ _safe_float('inf') → None
✅ _safe_float('-3.5')→ -3.5
```
