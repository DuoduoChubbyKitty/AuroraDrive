## 2. 世界模型的 next_image 来源与退化问题（核心发现）

### 2.1 代码实现

`dataset_v2.py:764-767`（索引构建阶段）：
```python
if self.enable_world_model and accepted:
    for i, r in enumerate(accepted):
        nxt = accepted[i + 1] if i + 1 < len(accepted) else r   # ★ clip末尾→复用自身
        r["next_frame_no"] = nxt["frame_no"]
```

`dataset_v2.py:862-865`（`__getitem__`）：
```python
next_fno = row.get("next_frame_no", fno)
next_path = _frame_path(clip_dir, fmt, next_fno)
if next_path is None:
    next_path = img_path      # ★ 极端降级：next缺图 → 复用当前帧（静默）
```

**两个退化路径**：
1. **clip 末尾**：`accepted[-1]` 没有 next → 复用自身 frame_no → **next_image == image**（自监督变成"预测自己"）
2. **next 帧缺失/被过滤**：`_frame_path` 返回 None → 复用当前帧 img_path（静默降级，无告警）

### 2.2 ★ 实测退化率

```
总样本 = 220（6 个 clip：23+12+2+22+70+91）
next_image 与当前帧完全相同的样本 = 117/220 (53.2%)
```

**即超过一半的世界模型训练样本的监督目标是"预测自己"**——loss 会假性下降（预测自己必然准确），模型学不到真正的"下一帧预测"能力。

**各 clip 退化情况**：每个 clip 的**最后一帧必然退化**；若 `require_active_control=True` 过滤掉零标签帧，clip 内断裂处也会退化。

### 2.3 clip 间连续性（任务描述的第4点）

**世界模型不支持跨 clip 的 next_frame**——`accepted` 列表是**单 clip 内构建**的（`dataset_v2.py:729` 每个 clip 独立处理）。clip 之间帧不连续，世界模型**不会**把 clip A 的末帧链到 clip B 的首帧。

**影响**：每次开始/停止录制 = 一个新 clip = world model 的时序链条断裂一次。短 clip（如 2 帧）的世界模型样本几乎全是退化样本。

## 3. 🔴 TemporalEncoder 在训练链路从未被激活（重大发现）

### 3.1 方案 A 的时序判定逻辑

`model_v2.py:1387`：
```python
seq_mode = (other_batch != seq_len and seq_len > 1
            and self.temporal_encoder is not None)
```

- **部署时**：`image=[8,3,180,320]` + 其他分支 `[1,...]` → `other_batch(1) != seq_len(8)` → **seq_mode=True** → 时序激活
- **训练时**：`image=[8,3,180,320]`（batch_size=8）+ 其他分支 `[8,...]` → `other_batch(8) == seq_len(8)` → **seq_mode=False** → **时序不激活**

### 3.2 实测验证

```
训练态: image [8,3,H,W] + lane [8,...] (batch=8 单帧)
  temporal_feat = None   ← ★ 时序分支未激活

部署态: image [8,3,H,W] + lane [1,...] (时序窗口)
  temporal_feat shape = (1, 128)   ← 时序激活
```

### 3.3 根因

`dataset_v2.py:837` 只产出**单帧** `image`，`train_v2.py` **不构造帧序列**（grep `feat_seq`/`history`/`frame_seq` 全空）。训练时 DataLoader 的 batch 维被 `seq_mode` 判定为"训练批次"而非"时序窗口"。

**⟹ 训练链路喂的是单帧，TemporalEncoder 从未在训练中被激活。** 时序能力只存在于部署推理路径，**训练时完全没有梯度流经时序分支**（`temporal_proj` 零初始化 + 时序分支不触发 → GRU 梯度永远为 0）。

## 4. action 的语义与来源

### 4.1 action = CSV 的 steer/throttle/brake（同一来源）

`dataset_v2.py:874-878`：
```python
sample["action"] = torch.tensor(
    [max(-1.0, min(1.0, steer)),
     max(0.0, min(1.0, throttle)),
     max(0.0, min(1.0, brake))],
    dtype=torch.float32)
```

**与 CSV 标签是同一个东西**（steer∈[-1,1]、throttle/brake∈[0,1]，归一化区间一致）。录制端 `RecordEngine.swift:247` 的 CSV 表头就是 `t_sec,frame,steer,throttle,brake`。

### 4.2 专家模式录制的 action 来源

`RecordEngine.swift:376` `appendFrame(image:steer:throttle:brake:)` ——录制时调用方传入当前控制量。**专家（人类）驾驶时**，这些值来自输入设备（键盘/手柄）的实时读取；**自动驾驶时**，来自模型输出。

**✅ action 来源无问题**——只要录制时传了控制量，CSV 就有。

## 6. 录制时长/帧数/场景建议

### 6.1 世界模型的最小 clip 长度

- **每帧需要一个 next_frame** → clip 必须 **≥2 帧**才有有效的世界模型样本
- **但 2 帧只有 1 个有效样本**（末帧退化）→ 实用最少 **≥10 帧**
- **clip 越长，退化率越低**（退化只发生在末帧）：
  - 10 帧 → 退化率 1/10 = 10%
  - 30 帧 → 退化率 1/30 = 3.3%
  - 91 帧 → 退化率 1/91 = 1.1%

### 6.2 TemporalEncoder 的 8 帧时序

- **训练链路当前不支持多帧**（§3.3）——即便录了 8 帧连续，训练时也喂不进去
- **要让时序训练生效**，需要改造 `dataset_v2` 产出帧序列 + `train_v2` 构造 `[N,3,180,320]`（而非 `[B,3,180,320]`）
- **录制端建议**：单次录制 **≥30 帧**（≥1.2秒@24fps），保证至少能取到 3 个 8帧窗口

### 6.3 场景建议

| 场景 | 价值 | 帧数建议 |
|---|---|---|
| 直道 | 基线，验证 pipeline | ≥30 帧 |
| 弯道（左/右） | 训练 steer 非零 | ≥30 帧/弯 |
| 加减速 | 训练 throttle/brake 非零 | ≥20 帧 |
| 检测目标（前车/行人） | 训练检测框分支 | ≥20 帧/目标 |
| 第三视角（TPV） | 用户硬需求 | 全部 |

### 6.4 ★ 一次性建议

> **单次录制 ≥60 帧（≥2.5秒@24fps），场景含直道+至少一个弯道，第三视角，控制量非零。**
> 这样：世界模型退化率 ≤1.7%、有弯道标签、满足未来 8 帧时序窗口需求。
> **最少 10 个这样的 clip**（总 ≥600 帧）才能开始有意义的训练。

## 7. 联合训练的数据要求（`--enable_world_model`）

`train_v2.py:1976-1986` 的 world loss 触发条件：
```python
if (enable.get("world_model") and aux is not None
        and aux.get("pred_next_fused") is not None
        and batch.get("next_image") is not None):
    l_world = F.mse_loss(pred_next[:, :img_feat_dim], next_img_feat)
```

**三个条件**：
1. `enable_world_model=True`（CLI `--enable_world_model`）
2. `aux["pred_next_fused"]` 非空（需 `return_aux=True` + `action` 非空）
3. `batch["next_image"]` 非空（需 `dataset.enable_world_model=True`）

**现有数据缺什么**：
- ❌ `next_image` 53% 退化（条件3"满足"但监督无效）
- ❌ `action` 在旧5 clip 全零（条件2的 action 会是零向量 → world model 学"无动作下的下一帧"）
- ✅ 新 clip 有非零 action（但画面是桌面截图）
