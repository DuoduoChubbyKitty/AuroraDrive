## 4. 修复根因复验（读码）

**commit `b2877ad` 的修复**（`EngineMain.swift:1331-1338`）：

```swift
// ⚠️ 必须**同时**改 st.digestMode（DriveState 属性）——
//   否则下一帧 tick 的同步段 `if controlEngine.digestMode != digestMode`
//   会用旧的 st.digestMode（false）把 controlEngine.digestMode
//   覆盖回 false。
st.digestMode = v                          // ← 修复：同时改 DriveState 属性
if st.controlEngine.digestMode != v {
    st.controlEngine.digestMode = v
```

**修复前**（bug）：只改 `controlEngine.digestMode`，没改 `st.digestMode` → 下一帧 tick 同步段用旧值覆盖回 false。
**修复后**：同时改 `st.digestMode` → tick 同步段读到的是新值 → **不再覆盖**。

✅ **实测印证**：开 digest 后 10 秒（~330 帧 tick）`digestMode=true` 始终保持 → **覆盖问题已消失**。
