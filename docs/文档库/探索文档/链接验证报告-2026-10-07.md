### 1.2 扫描器逻辑（关键去噪）
本小姐自写扫描器 `/tmp/e5scan/scan2.py`，要点：
1. **剔除 fenced code block**（` ``` ` / ` ~~~ ` 围栏内整段跳过）——否则 `性能审计笔记.md` 里 `[0](repeating: 0, count: 256)` 这种 Swift 断言会被误判成链接，单文件就能造上百条假断链。
2. **剔除 inline code span**（`` `...` `` 内不解析链接）。
3. **NFC 归一化**比较路径与磁盘文件名（macOS HFS+/APFS 存 NFD，`./MaaNTE/docs/jp/トラブルシューティングマニュアル.md` 是全仓唯一 NFD 文件名，已确认扫描器正确处理）。
4. 链接目标做 `urllib.parse.unquote` + NFC，再相对文档目录 join；外部协议（http/mailto/#锚点）跳过。
5. 对每条断链，全仓按 basename 查找「别处是否存在」用于给修复建议。

