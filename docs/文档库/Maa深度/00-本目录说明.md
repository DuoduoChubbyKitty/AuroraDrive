# Maa深度文档 · 目录说明

> 生成：2026-10-07（文档库整理）

## 这个目录是什么

本目录 15 篇文档是 **MaaNTE（Windows 版《异环》自动化项目）的逆向分析记录**，
用于指导 AuroraDrive 的功能移植。**它们描述的是上游项目，不是本仓库的代码。**

| 文件 | 性质 |
|---|---|
| `MAA深度文档_{架构,功能,扩展,完整}篇.md` | MaaNTE 四篇体系化分析 |
| `Maa-09` ~ `Maa-15`（7 篇） | 按模块的深度拆解（入口/基础设施/Navi导航/地图传送/小游戏/实时辅助/生活任务） |
| `MaaNTE移植对照表.md` | 移植进度对照 |
| `MaaNTE-macOS适配验证.md` | macOS 适配可行性验证 |
| `MAA移植难度评估报告.md` | 移植工作量评估 |
| `ROI反推规则.md` | 画面 ROI 推导方法（本项目 OCR/截图的 ROI 依据） |

## ⚠️ 时效性说明

**这些文档不会随 AuroraDrive 的代码更新而更新**——它们记录的是"当时怎么分析的 MaaNTE"。
引用时注意：

1. **移植已完成或已放弃的部分**：本项目已从 MaaNTE 移植了多项能力（技能宏、地图数据、
   ROI 规则等），也放弃了一些不适用的（如 Windows 专属的 Win32 控制器路径）。
   具体现状请看 `../自动驾驶与功能/` 下的现行文档。
2. **MaaNTE 上游若已更新**，本目录的分析可能滞后——需要时重新分析上游。
3. **本项目新增的能力（如 AI 助手/LLM 渠道聚合）与 MaaNTE 无关**，不在本目录范围。
