### 2-2-2 双进程架构（UI 进程 + `--engine` 引擎进程）

**同一份可执行文件，两种角色**——UI 侧探测不到引擎就 **spawn 自己**：

| 环节 | 证据 |
|---|---|
| 启动探测 → spawn | `EngineClient.startup()` → `spawnEngine()`，`process.arguments = ["--engine"]` |
| 引擎 stdout/stderr | 重定向到引擎日志 `engineLogPath` |
| 共享内存 | `EngineFrameShm.name`，`pixelsOffset` **28672**（由 `maskOffset + maskRegionBytes` 页对齐算出） |
| ⚠️ 布局变更 | 旧版 `pixelsOffset` = **20480**；v3 为给掩码区让位后移到 **28672** |
| 协议版本 | `protocolVersion = 3`——v3 因 shm 插入掩码区而升版本 |
| 版本不匹配 | 实心跳 + 协议不符 → 判 stale（`relaunchStaleEngine()`） |
| 发布 | `tickOnce()` → `shm?.publish(...)` + `shm?.publishMasks(...)` |
| 控制通道 | Unix socket `engine.sock`（`EngineSocketServer`） |
| 节奏 | 引擎 tick **20Hz** / 心跳 1Hz（心跳队列 `hbQueue`） |
| 降级 | spawn 失败 → 回退本地模式（`EngineClient.startup()`） |
