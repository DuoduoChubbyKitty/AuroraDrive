## 一、用途与**边界**（最重要的一段）

文件头 `:7–12` 写死了一条边界，**必须遵守**：

> ⚠️ 本先验**只提供航向，绝不提供横向偏差**。
> 横向（车偏左还是偏右）必须来自实时视觉（车道线/可行驶区），
> 因为**地图是玩家标注版，与实景存在米级偏差**，拿它做横向会直接带偏方向。

用途：车道线全部丢失（路口 / 掉头 / 遮挡 / 游戏卡顿）时，提供「路往哪拐」这一维先验。

## 三、★ 三次重大修正（此前版本全错，用户当场指出）

文件头 `:18–31` 完整记录了这三次修正 —— **这段是本文档最有价值的部分**：

### 修正 1 · 阈值（45 → 70）
- 早先误用阈值 **45** → 多抓 **16.1%** 的**等高线噪声**（实测 677,265 像素）
  → **弯道打点 83% 落在建筑/等高线上**
- 全图灰度实测分布：

| 灰度区间 | 占比 | 是什么 |
|---|---|---|
| 0~8 | 47.6% | 纯黑 |
| 16~24 | 45.0% | 暗底 |
| 24~56 | 4.8% | 建筑 + 等高线 |
| **80~88** | **1.95%** | **真路面（唯一）** |

- **连通性实测**：阈值 **70 → 98.6%** ✓；阈值 45 → 16.1%（噪声）；阈值 **80 → 掉到 37%**（断路易）
- ⟹ **阈值 70 是正确的**，80 会打断道路。

### 修正 2 · 缩放（整除截断丢地图）
- 旧代码 `H//2048 = 6`（**整除截断**）→ 每格实为 6px 而非 6.375px
- 且 `2048*6 = 12288` **丢掉地图最后 768px（468 m）** → 坐标系统性偏移
- 实测后果：**66.6% 的打点离真路面 > 24 m**
- 修正为 BOX 缩放到精确 **6.375 px/格**、覆盖全幅后：

| 指标 | 修正前 | 修正后 |
|---|---|---|
| 偏差中位 | — | **0.0 m** |
| 1.8 m 内占比 | — | **94.3%** |
| 9.8 m 内占比 | — | **100%** |

### 修正 3 · 断裂（斑马线被挖成缝）
- 底图**斑马线**处灰度 **17~68**（真路面 80~88）
- 二值化后斑马线被**挖成 837 处窄缝** → 射线打到缝里就"断"，路网不连通
- 用**形态学闭运算（半径 16px）**填缝 → **断裂减少 64%**，连通性恢复到 **98.6%**

**底图性质**：**矢量风格道路线稿** —— 灰色粗线 = 道路（中位宽 27~30px = **16~18 m** 路面）、
黑色带 = 河流、深色底 = 空地。

## 七、方向约定（与 `toPose` 罗盘角一致）

```
罗盘角 0°  = 正北 = 地图上方（图像 −Y）
罗盘角 90° = 正东 = 地图右方（图像 +X）
由 PCA 主轴 (dx,dy)（图像坐标，dy 向下）换算：compass = atan2(dx, -dy)
```

## 八、与 `RoadCornerGuide` 的分工

| | `RoadMapPrior` | `RoadCornerGuide` |
|---|---|---|
| 数据 | 2048² 二值位图 | 3135 个打点 |
| 回答 | 「**这里是不是路**」「路往哪拐」（连续场） | 「**前方第几个弯/路口**」「转多少度」（离散点） |
| 典型用途 | 交接条件①「在路上」、走廊容差 | 弯道转向量、路口选出口 |
| 尺度 | 3.89 m/格 | 提前量 40 m |

**两者互补，都不提供横向偏差。**
