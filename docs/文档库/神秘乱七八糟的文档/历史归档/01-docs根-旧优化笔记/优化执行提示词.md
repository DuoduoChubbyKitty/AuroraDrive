## 第 3 步：约束（红线，违反即失败）

### 绝对不能碰

| 类别 | 清单 | 原因 |
|---|---|---|
| **Vendored 内部逻辑** | `GooseEngine` 的 `ensureSpatialScaler` / `ensureFrameInterpolator` / `ensureTexture` / `interpolateFrame` / `encodeUpscale` | 注释声明 "kept byte-for-byte"，且这些缓存**已正确**（有尺寸检查） |
| **控制逻辑** | 限速三级刹车（`SpeedLimitGuard`）/ 降级链（`DegradeStateMachine`）/ 按键注入（`ControlEngine`）/ 专家模式门禁 | **涉及行车安全** |
| **TCC 权限路径** | 进程链继承 / fail-fast 退出 | 权限模型，改了就崩 |
| **30fps 红线** | 任何降低 tick / 采集 / 推理**频率**的改动 | 用户明确要求 |
| **用户数据** | `data/raw_clips` / `models/` | 训练数据 |
| **已优化项** | `SpeedOCRReader` 三重闸门 / `RecordEngine` 背压 / `EngineClient` seq 早退 / `CaptureEngine` vImage 缩放 / `ObstacleOverlay` 去阴影 / `tickEngineMode` 的 8 处先比后写 | **已是好实践，改了是倒退** |

### 功能零缩减

- **不减少任何循环**
- **不降低任何频率**（30Hz tick / 5Hz OCR / 10Hz 定位都不许降）
- **不删除任何功能**
- **不缩减任何 UI 元素**
- 只允许**代码层面**的改动（折叠、缓存、复用、门禁、memcpy 替代）

### 代码质量

- **不许写 hack**（`if false`、注释掉代码、临时变量绕过）
- **不许留 TODO**
- **注释要写"为什么"**，不是"做什么"
- **改动要最小化**——能改 1 行不改 10 行
- **每一项改动都要有回滚路径**（单行最好）

### 视觉

- **不许改变视觉**（除了改动 5 的 `blur` 需用户确认）
- **改动 5、6 必须截图对比**再决定是否保留
- 用户的视觉偏好：**黑色不透明玻璃质感**、**有空间感光斑**、**高对比度**、**拒绝奶白/泛白**
