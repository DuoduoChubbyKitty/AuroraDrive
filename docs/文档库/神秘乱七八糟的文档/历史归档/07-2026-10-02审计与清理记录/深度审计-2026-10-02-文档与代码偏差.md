## §3 代码缺陷（逻辑真错，不是注释错）

### §3.1 【缺陷⑨】地图段限速**全线失效**

**因果链**（每一环都已核）：

1. `Sources/AuroraDrive/Agent/DriveSegmentController.swift:59` —— `var overridesVision: Bool { mapSteer != nil }`
   → **限速是否生效，取决于 `mapSteer`，与 `speedLimitKmh` 无关。**
2. `DriveSegmentController.swift:196`（`stepFromVision` 进地图段）→ 返回 `mapSteer: nil, speedLimitKmh: lim`
   → **给了限速，但 `mapSteer` 是 nil ⇒ `overridesVision == false`。**
3. `DriveSegmentController.swift:236` —— `let lim = speedLimitForCorner(nil, spd, radius: nil)`
   → `:405–410` 该函数 `hit == nil` 时返回 nil ⇒ **地图段稳态永远没有限速值。**
4. `DriveSegmentController.swift:382`（`stepHandover`）→ 返回 `mapSteer: nil, speedLimitKmh: 30.0`
   → **同样被丢掉。**
5. 消费端 `AuroraDriveApp.swift:5368` `if segDecision.overridesVision, let ms = segDecision.mapSteer {`
   → `:5372–5376` 才压油门 `currentCommand.throttle = max(0.0, min(currentCommand.throttle, max(0.0, min(0.35, cap * 0.12))))`
   → **进不来。** `:5379–5381` 的 `else { logSegmentIfNeeded(segDecision, before: nil) }` 把限速**静默丢弃**。

**结论**：`DriveSegmentController` 自己的注释写着「路口一律限速 30（保守），并压住油门」「交接未完成期间：保守（不加油、不给转向）」——
**实测这两句在当前代码下都不成立**。`stepMapTurn`（`:230–235`）转向是有的，所以"一直没转向"不成立；
但**"压住油门"从来没生效过**，因为 `overridesVision` 只看 `mapSteer`。

**性质**：这是**真 bug**，不是文档问题。修法见 §5。

### §3.2 【缺陷⑪·新】`stepHandover` 12 秒兜底可能活锁（未实测，仅静态推演）

- `DriveSegmentController.swift:377–381`：若交接超 `12.0 s` → `segment = .straighten`（**直接赋值**）。
- 但清 `handoverOrigin` 的只有 `reset()`（`:413–428`）。
- `.straighten` 一旦 `mag <= straightenDoneDeg` → `:312–320` 立刻又回 `.handover`，`handoverOrigin` 被**重新赋值**。
- → 存在 **straighten ↔ handover 反复横跳、永不收敛**的可能。
- ⚠️ **标注：静态推演，未实测**。需要真实游戏负载 + 真实位姿流才能确认。**不要当成已证实的 bug 用。**

### §7.1 测量方法学教训（血泪，别再踩）

1. **工具会骗人**：`n=1` 会撞上懒加载（cornerAhead 首测 31.4ms，预热后 p50 0.000–0.003ms）。
2. **`Thread.sleep` 会阻塞写回**，测出来的数不是产品行为。
3. **输出必须先跟已知事实对上**，否则整批数据作废。
4. **任何优化都要在 `AURORA_*` 开关后面**，能 ABBA 切换。
5. **每个优化都要等价性证明**（例：空间索引对拍 91 命中 0 不一致）。
6. **区分"省 CPU"和"腾出主线程"** —— 这俩不是一回事。
7. **几何/方向类 bug 靠读代码看不出来**，必须算。
8. **`sample` 会污染被测对象**（引擎推理 295ms → 采样下 378ms），一律用进程内 `PerfBus`。
9. **`find ~ -maxdepth 4` 会挂死 >60s**，用精确路径。
10. **.app 与 .build 的二进制绝不能比 SHA-256**（构建布局非确定，实测 84229 字节差异、最大连续断层 5,548,039）。
