> 1. 自己看工具文档、自己调用、自己学会新技能  
> 2. 不会时请求人类接管  
> 3. 看人类录屏演示并学习

## 一、调研结论（TL;DR）

### ✅ 它真正具备的能力

| 能力 | 实际情况 | 证据来源 |
|---|---|---|
| **自己探索新工具** | ✅ **真有**，通过 `code_run` 可以装依赖、写脚本、调试，然后把成功的流程存到 L3 记忆 | `ga.py:527 do_start_long_term_update()` |
| **自动结晶技能** | ✅ **真有**，任务成功后调用 `start_long_term_update` 工具，LLM 会把"经验证的步骤"提炼成 SOP 写入 `memory/` 目录 | `memory/memory_management_sop.md` |
| **请求人类帮助** | ✅ **真有**，`ask_user` 工具可以问问题，且在转数超标或卡住时会强制调用 | `ga.py:330 do_ask_user()` + `ga.py:584` 强制触发逻辑 |
| **分层记忆系统** | ✅ **真有**，5 层记忆（L0 元规则/L1 索引/L2 环境事实/L3 技能SOP/L4 会话归档），确实比单纯的 embedding 检索高效 | `agent_loop.py` + `memory/` 目录结构 |

### ❌ 它**没有**的能力

| 你的期望 | 实际情况 | 为什么做不到 |
|---|---|---|
| **看人类录屏并学习** | ❌ **完全没有**，没有任何视频分析、屏幕录制学习的代码 | 它只有"截图+OCR+UI 检测"，没有"时序视频理解"能力 |
| **观察人类操作并复现** | ❌ **没有**，不能"你操作一遍，它学会" | 它的学习是"自己试错+成功后记住"，不是"模仿学习" |
| **主动说"我不会，请演示"** | ⚠️ **部分能力**，它会在卡住时 `ask_user` 问你建议，但不会主动说"请你录屏演示" | `ask_user` 只能问文本问题，不能接收视频输入 |

## 二、自演化机制的真实工作流程

### 2.1 第一次执行任务（以"自动钓鱼"为例）

```
[用户] 帮我在游戏里自动钓鱼

[GenericAgent]
  ↓ (1) 读取 L2/L3 记忆，发现没有"钓鱼"相关技能
  ↓ (2) 开始探索：
       - code_run: 装 pyautogui（假设需要）
       - code_run: 写脚本 fishing_attempt_1.py（点击某个坐标）
       - code_run: 运行 fishing_attempt_1.py
       - ❌ 失败（坐标不对）
  ↓ (3) 修正：
       - code_run: 用 ui_detect.py 检测"钓鱼"按钮位置
       - code_run: 改 fishing_attempt_2.py（用检测到的坐标）
       - code_run: 运行 fishing_attempt_2.py
       - ✅ 成功（钓到鱼了）
  ↓ (4) 结晶技能：
       - 调用 start_long_term_update 工具
       - LLM 被触发一个特殊 prompt："提取最近任务中【验证成功】的步骤"
       - LLM 写文件 `memory/fishing_sop.md`:
         ```
         # 钓鱼技能 SOP
         前置条件：游戏已打开，角色在可钓鱼区域
         步骤：
         1. 用 ui_detect 检测"钓鱼"按钮（关键词：fishing/钓鱼）
         2. 点击检测到的坐标
         3. 等待 3 秒
         4. 检测是否有"获得物品"提示（验证成功）
         ```
```

### 2.2 第二次及之后执行"钓鱼"任务

```
[用户] 帮我钓鱼

[GenericAgent]
  ↓ (1) 读取 L3 记忆，发现已有 `fishing_sop.md`
  ↓ (2) 直接按 SOP 执行：
       - code_run: 调用 ui_detect
       - code_run: 点击坐标
       - code_run: 验证成功
  ↓ (3) 完成，耗时 <10 秒（第一次可能要 3 分钟）
```

**关键证据**（代码）：
```python
# ga.py:527
def do_start_long_term_update(self, args, response):
    '''Agent觉得当前任务完成后有重要信息需要记忆时调用此工具。'''
    prompt = '''### [总结提炼经验] 既然你觉得当前任务有重要信息需要记忆，请提取最近一次任务中【事实验证成功且长期有效】的环境事实、用户偏好、重要步骤，更新记忆。
**只能提取行动验证成功的信息**：
- **环境事实**（路径/凭证/配置）→ `file_patch` 更新 L2，同步 L1
- **复杂任务经验**（关键坑点/前置条件/重要步骤）→ L3 精简 SOP
**禁止**：临时变量、未验证信息、通用常识
'''
    # LLM 被这个 prompt 触发后，会自己写 SOP 文件到 memory/
```

## 三、它的"学习"本质是什么？

### 3.1 真实机制：**试错 + 成功路径结晶**

- **不是** 模仿学习（Imitation Learning）
- **不是** 强化学习（Reinforcement Learning）
- **是** 经验提炼（Experience Distillation）

**类比**：
- ❌ 不像人类看师傅做一遍就会（它不会）
- ✅ 像程序员写代码：尝试 → 报错 → 改代码 → 成功 → 记笔记

### 3.2 为什么它不能"看人类演示"？

**技术原因**：
1. **没有视频理解能力**  
   - 它只有 `ui_detect.py`（静态截图 OCR + 控件检测）
   - 没有"连续帧分析"、"动作序列提取"功能
   
2. **没有"动作轨迹记录"工具**  
   - 它不能记录"用户点了哪里"、"用户按了什么键"
   - `ask_user` 只能问文本问题，不能说"请你操作一遍并录制"

3. **LLM 本身不支持视频输入**  
   - 即使你给它录屏文件，它也没有工具去解析成"动作序列"
   - 就算是 GPT-4V/Gemini Vision，也只能理解"单张图片"，不能理解"视频里的操作流程"

## 四、它能做到的"不会就问人类"

### 4.1 真实的 ask_user 工具

```python
# ga.py:330
def do_ask_user(self, args, response):
    question = args.get("question", "请提供输入：")
    candidates = args.get("candidates", [])  # 可选的候选答案
    result = ask_user(question, candidates)
    yield f"Waiting for your answer ...\n"
    return StepOutcome(result, next_prompt="", should_exit=True)
```

**实际效果**：
```
[GenericAgent 自己探索时]
  ↓ 尝试了 5 次都失败
  ↓ 触发强制 ask_user（超过阈值）
  
[弹出问题给用户]
"我尝试了多次自动钓鱼，但总是找不到按钮。你能告诉我：
1. 按钮在屏幕哪个区域？
2. 按钮上的文字是什么？
3. 需要先按什么键打开菜单吗？"

[用户输入]
"先按 F3 打开地图，然后点左下角'前往海边'传送点"

[GenericAgent 拿到答案]
  ↓ 继续执行新策略
  ↓ 成功后把"F3→点左下角"写入 SOP
```

### 4.2 强制触发 ask_user 的条件

```python
# ga.py:584
if turn >= 180:
    next_prompt += f"\n\n[DANGER] Turn {turn}. Must call ask_user to summarize progress and get direction. No more blind retries."
```

**翻译**：  
- 如果执行了 180 轮（约 1 小时）还没成功，强制调用 `ask_user` 问用户
- 防止它无限循环浪费 token

## 五、对"异环游戏自动化"的适用性

### 5.1 ✅ GenericAgent 能做的（游戏场景）

| 能力 | 如何实现 | 示例 |
|---|---|---|
| **截图识别 UI** | `ui_detect.py`（OCR + 控件检测）| 识别"领取奖励"按钮位置 |
| **点击/按键** | `code_run` 调用 `macljqCtrl`（macOS 键鼠控制）| 点击按钮、按 WASD 移动 |
| **记住游戏地图** | L2 记忆存"海边坐标 (X, Y)"| 下次直接传送 |
| **记住任务流程** | L3 SOP 存"钓鱼步骤：F3→点传送点→等待加载→按 Enter 开始钓鱼"| 复用流程 |
| **不会时问你** | `ask_user("这个任务我不会做，你能告诉我第一步该点哪里吗？")` | 人工介入引导 |

### 5.2 ❌ GenericAgent 做不到的（游戏场景）

| 限制 | 原因 | 替代方案 |
|---|---|---|
| **看你玩一遍就学会** | 没有"录屏分析 → 提取动作序列"功能 | 你得用 `ask_user` **文字描述**流程 |
| **理解 3D 场景** | UI 检测只能识别 2D 界面元素，不能理解"前方有个敌人" | 需要额外的 Vision LLM 分析 |
| **实时反应速度** | 每步都要调 LLM 推理（2-5 秒延迟）| 不适合需要即时反应的战斗 |
| **复杂策略决策** | 它是"线性 SOP 执行器"，不是"策略规划 AI" | 简单重复任务可以，复杂决策树不行 |

## 六、最终建议：GenericAgent 还值得用吗？

### 6.1 适合你的场景 ✅

如果你的需求是：
- ✅ **自动化重复任务**（领奖励、钓鱼、跑商）
- ✅ **任务流程已知**（你能文字描述步骤，或者让它试错几次后记住）
- ✅ **不需要实时反应**（回合制、菜单操作、定时任务）
- ✅ **希望它越用越聪明**（第一次慢，之后快）

**推荐组合**：
```
GenericAgent（大脑）
  ↓ 调用工具
MaaNTE 技能（手脚，25 个现成技能）
  ↓ 执行游戏操作
异环游戏
```

### 6.2 不适合你的场景 ❌

如果你期望：
- ❌ **看你玩一遍就会**（它不能分析录屏）
- ❌ **实时战斗辅助**（2-5 秒延迟太高）
- ❌ **完全自主探索**（需要人类引导第一次成功，之后才能复用）
- ❌ **复杂策略决策**（它是"流程执行器"，不是"策略 AI"）

**那就别用 GenericAgent**，直接选方案 B：自己在 AuroraDrive 里手写最小 Agent Loop（用 Pollinations Vision API + 你现有的技能）。

## 八、下一步决策

基于以上调研，你现在有两个选择：

### 选项 A：用 GenericAgent + MaaNTE
**前提**：你愿意第一次任务时通过 `ask_user` 文字引导它（告诉它"先按 F3，再点传送点"），之后它会记住。

**优点**：

**缺点**：
- ❌ 不能看录屏学（你得文字描述）

**缺点**：
- ❌ 工作量是 GenericAgent 的 3-5 倍
