## 3. 边界（红线，绝不越过）

| 允许 | 禁止 |
| --- | --- |
| 点菜单、进面板、翻页、返回 | **不充值、不消费真实货币** |
| 用游戏内资源（用户明确授权） | **不退出/切换账号** |
| 打小游戏、进副本 | **不改游戏设置**（尤其分辨率/画质/按键） |
| 移动角色、传送 | **不改窗口大小/位置**（用户明确拒绝过） |
| 领取日常奖励 | 不删除角色/装备/存档 |
| 点击不确定的按钮前先截图问 | 不做不可逆操作 |

**遇到以下情况立即停下来问用户：**
1. 界面弹出「确认购买」「确认消耗 XX 货币」——即使资源无限，也先问
2. 需要输入文字/密码
3. 任何看起来像「删除」「重置」「解绑」的按钮
4. 连续 3 次点击没反应（可能是操作方式不对，别硬试）

## 3.5 启动流程（关键，不做会卡死）

**《异环》启动后不会自动登录，必须在游戏窗口上点一下鼠标才会开始。**

顺序：

```
① open -a 异环            启动客户端
② 等 10~20 秒              等启动器/加载页出现
③ computer_observe         看窗口出来了没
④ computer_click           在游戏窗口【任意位置】随便点一下鼠标
⑤ 等他加载                 耐心等，可能 1~3 分钟（首次进图更久）
⑥ computer_observe         确认进到游戏世界了再继续
```

要点：
- **第 ④ 步是必须的**，不点的话等一万小时也进不去（用户原话："就算等10,000小时都没有"）
- 点的是**游戏窗口范围内的任意位置**，不需要点特定按钮
- 点完不一定立刻有反应，加载页可能停留很久，**不要重复点、不要乱点**
- 判断"进游戏了"的依据：看到 3D 世界 / HUD（左上小地图、右上快捷键栏、底部血条）

## 4. 操作循环（每一步都按这个走）

```
① computer_observe(游戏 pid, screenshot=required)
② 用我自己的视觉能力看图，判断当前在哪个界面
③ 决定下一步：点哪里 / 按什么键
④ computer_click 或 computer_press_key（用 elementIndex 优先，坐标兜底）
⑤ 回到 ①，看结果
```

**关键纪律：**
- **每次点击后必须重新 observe**，不要凭记忆连点
- **坐标计算**：游戏窗口 frame 是 `(0, 33, 1470, 923)`。
  截图里 1280×803 空间的坐标 → 屏幕坐标：
  `screen_x = x_1280 × (1470/1280)`
  `screen_y = y_1280 × (1470/1280) + 33`
- 点不中就换个位置再试，**同一位置最多试 2 次**

## 5. 每采集一批 → 立刻验证（闭环）

```bash
python3 tools/maa_node_audit.py      # 2.4 秒出结果

看「❓ 数据不足」是否下降、是否新出现「✅ 直接可用」。
**没下降就说明这个界面采错了或没进对地方**，回去重采，不要攒着。

## 8. 我已知的事实（不用重新验证，直接用）

- 窗口固定 `1470×923 @ (0,33)`，**不许动**
- 截图来自 macOS 自带工具时是 `2940×1912`，游戏窗口在 `y=66` 起，高 `1846`
- 裁窗口 → 缩到 `1280` 宽 → 得 `1280×803`，这是比对空间
- MaaNTE 基准是 `1280×720`，**高度差 83px**
- 规则：**顶部锚定 UI 位置不变；底部锚定 UI 下移 83px**
- `MaaControllerSetOption(ScreenshotTargetLongSide = 1280)` 是对应的运行期配置
- 高分 ≠ 同一控件（白色按钮/圆底图标会互相误匹配），**判读必须靠眼睛看图**
