## 3. Mac 版状态

### 结论：Mac 版 = Apple Silicon 上运行的 iOS 版（App Store 通用 App），公测首日即上线，与移动端同步更新。

**证据链**：
1. **公测定档公告**（2026-02-26）明确：「全平台公测正式定档 2026年4月23日，届时将同步上线 **PC、安卓、iOS、Mac、鸿蒙、PlayStation®5**」。https://yh.wanmei.com/news/gamebroad/20260225/261033.html
2. **App Store 页面**标注「iPhone、iPad、Mac」，即通用（Universal）App。https://apps.apple.com/cn/app/id6514281568
3. **iTunes API**：`supportedDevices` 含 `MacDesktop-MacDesktop`，`features: ["iosUniversal"]`。https://itunes.apple.com/lookup?id=6514281568&country=cn
4. **官方 PatcherSDK 更新清单**：`MacOS/laohu_9` 与 `iOS/laohu_9` 同为 `version 1.4.0 / versioncode 140 / force=1`，且 Mac 的更新 URL 指向 iOS App Store 链接 `https://apps.apple.com/cn/app/id6514281568` —— 证实 Mac 跑的就是 iOS 包。（本机容器文件 `PatcherSDK/internal/update.0.json` / `update.1.json`）
5. **官网首页**下载区有「支持 Apple Mac」徽标（`images/main260326/yy-tip-mac.png`），挂在 iOS 下载按钮上。

**Mac 与 PC/移动端差异**：
- 与 **iOS 完全同包**：版本号、资源、更新节奏完全同步（同一 App Store 版本 1.4.0/1.4.1）。
- 与 **PC（Windows/PS5）**：PC 有独立客户端（Windows 需预留 45GB+），且部分功能标注 PC 专属（如 1.3 的「F7 隐藏 UI」仅 PC 端）；Mac 版按 iOS 键位/触屏逻辑适配（本机项目提示词也注明「Mac 版键位与 Windows 版有实质差异」）。
- **Mac 系统要求**：本机游戏包 `LSMinimumSystemVersion = 14.00`；App Store `minimumOsVersion = 15.0`（iOS 侧要求）。**必须 Apple Silicon**（M 系列芯片）才能直接跑 iOS 版。
- 本机安装形态特殊：用户将 App Store 版 163GB 资源改写到外置盘（`com.pwrd.yh.ios` 容器 + 外置卷挂载 + `Documents/HT` 符号链接），详见工作区 `交接文档-异环外置盘.md`。这属于本机定制，非官方方案。

**更新同步性**：同步。1.4 的 App Store 版本（1.4.0，9-23 发布）与 Mac 端 PatcherSDK 强制更新（MAC_140 分支，1.4.0）同日生效；本机 10-06 的热更（App 1.4.1 / Res 1.4.13）也通过同一 iOS 包更新而来。
