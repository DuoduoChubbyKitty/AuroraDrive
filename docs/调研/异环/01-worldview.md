## 二、核心设定：异象 / 环 / 世界观基本规则

### 2.1 异象（Anomaly）——游戏世界的核心概念 【Wiki，游戏内档案文本】
> 一切于人类而言具有超自然、非现实属性的**生物、物体、现象、地点、迷因**的统称。异象现身的端由形形色色，但它们存在于这个世界上，本身便是最大的未解之谜。

- 出处：萌娘百科《异环/名词词典》https://zh.moegirl.org.cn/异环/名词词典 ；Fandom「Anomaly」https://neverness-to-everness.fandom.com/wiki/Anomaly
- 异象五类基本属性：**生物（俗称「歧骸」/Oddity）、物体、现象、地点、迷因**。生物与物体最常见且「本体必定为固定实体」；现象/地点/迷因本质上无确切实体，数量稀少。【Wiki】
- 异象等级（Ⅰ–Ⅹ级）：按维特海默值波动分级，Ⅰ级几乎不影响生活秩序，Ⅹ级（≤ -200）属「人类灭亡级别威胁」。分级只是能力强度概括，「有能力」≠「一定会」。如 Ⅶ 级异象「极漩」可致整个城市机能停滞或毁灭。【Wiki】
- 异象档案：含图片、编号、属性、俗称、权限、等级、故事、特性、奇点、风险评估、收容/担保情况、收容措施、实验记录、衍生异象说明。由「尤克阿什庭」档案员编写，是参考价值最高的异象资料。档案权限分五级：公开级 / 悬赏级 / 受限级 / 保密级 / 机密级（仅 A6 可调阅）。【Wiki】
- 衍生异象 / 伴生异象：与某异象有密切关联的为「衍生异象」（附属、进化/退化、变种等）；因其他异象活跃而同时出现活跃的为「伴生异象」（通常等级低）。【Wiki】
- 异象制品：用异象衍生物材料工业化加工的产品（日用品、食品、玩具、家具），可反映异象部分性质；龙头为「迈达斯科技」。【Wiki】

### 2.2 环（The Circle）——异象权力机关的总称 【官，游戏内索引 / Wiki】
> 「环」是世界对「异象权力机关」的总称。
> 狭义：五大公权机关 + 最高议庭 A6。广义：还包括民间异象猎人组织与个体。
> 理念为 **3C：控制（Control）、收容（Containment）、认知（Cognition）**。

- 五大公权机关与 3C 对应：
  - **异象管理局（Bureau of Anomaly Control / BAC）** = 控制。负责异象收容/泯除、涉异犯罪处理、灾害镇压。总部在海特洛市。下属 J.T.F 联合特遣队（基层外勤，普通人组成）、C.S.U 收容行动组（收容/泯除，普通人+异能者）、E.T.D 禁制机动队（全员强力异能者的王牌，共 7 个小队）、DSD 日常安全部门。【Wiki + Fandom】
  - **塞拉伊诺馆（Celaeno Compound）** = 收容。安置被收容异象，以「收容单元」形式。【Fandom】https://neverness-to-everness.fandom.com/wiki/The_Circle
  - **格赫罗斯岛（Ghroth Island）** = 收容。作为监狱运转（主角序章即被关押于此观察）。注意与 BAC 总部旁的海特洛拘留所（Hethereau Detention Facility）是两回事。【Fandom】
  - **尤克阿什庭（Yggash Court）** = 认知。负责情报与档案（异象档案由此机构编写）。【Fandom】
  - **零角实验室（Zerogon Laboratory）** = 认知。主导研究；旗下有科技公司「迈达斯科技」（Midas Technologies），下设图特研究所（弧盘专利）与奥德赛研究所（空幕专利）。【Fandom】
  - **最高议庭 A6（Supreme Tribunal A6）**：机密级档案唯一可调阅者，环的最高层级。【Wiki】
- 历史定位：「环」自古作为秘密守护者，收容异能者、收容并泯除异象、让怪事远离普通人；**40 年前向公众公开了异象与异能者的存在**。【Fandom 引用世界观 PV《NTE Worldview Trailer丨Where Strange Gets Interesting》https://www.youtube.com/watch?v=0T_BOZztEFw 】
- 六大家族（Six Major Families）：与五大公权并列的存在（受限级档案可调阅）。已知有「德沃夏克家族」（最富有、最浪漫，旗下粉爪银行、金苹果藏馆）。【Wiki + Fandom】

### 2.3 异能者 / 异能 / 代价 【Wiki】
- **异能者（Esper）**：人类中觉醒了异能的个体。分先天觉醒与后天契机觉醒两类；部分异能者有兽化、鬼角、异色皮肤等外貌差异；寿命因异能而异（有的更短、有的更长、有的近永恒）。【Wiki】
- **异能（Esper Ability）**：从普通人类身上觉醒的超自然能力，按系谱分为 **光 / 暗 / 灵 / 相 / 咒 / 魂** 六种（英文 Cosmos / Chaos / Anima / Lakshana / Incantation / Psyche）。不一定都强大，有的很滑稽。英文 Fandom 与中文词典均给出系谱发端定义（光=联通秩序、暗=离散秩序、灵=自然元素、相=物质层面、咒=语言媒介可召唤其他维度存在、魂=精神心理层面）。【Wiki + Fandom + 萌娘百科《异环/典故》https://zh.moegirl.org.cn/异环/典故 】
- **代价**：所有异能觉醒都需支付「代价」——身体机能/精神状态改变或抽象「因果代价」（如获得不可逆弱点）；不一定遵循等价交换；一般一次性支付。【Wiki】
- **异能专利**：经异能者参与制作/发明的产物，分「异能技术」「异能造物」两大类（例：弧盘、空幕）。【Wiki】
- **同源说**（学界假说）：人类异能可能与异象发端于同一来源。【Wiki】

### 2.4 维特海默值（Wertheimer Index）——背离现实的检测标准 【Wiki + Fandom】
- 衡量目标对象**背离现实强度**的检测值，以现实为锚点。异象一般 < -1，异能者 > 1；普通人因日常受异象/异能影响，实际值通常在 -1 ~ 1 之间；完全不偏离现实的理论值为 0。
- 绝对值越大，背离现实越强。也是异象定级的重要参考。
- 大范围测量已普及（以「维特海默塔」为主）；点对点精确测量技术上未实现。
- **主角异能者·零是迄今唯一无法检测出维特海默值的异能者**。【Wiki + Fandom】

### 2.5 异象管理相关流程术语 【Wiki】
- **奇点（Nexus）**：对异象施加特定干预时，导致其内外表现剧烈变化的临界点；单个异象的奇点具有唯一性，在收容/泯除中起关键作用。主角的能力就是「快速定位奇点」。
- **收容 / 临时收容**：关键手段限制隔离异象；临时收容适用于威胁低/较稳定的异象。容器称「收容体」。
- **解离**：已被收容的异象自主突破收容状态的行为。
- **泯除（Nullification）**：将异象在人类世界的存在抹除的行为；不代表彻底抹杀，可能再次现世。
- **捕获**：获取异象活动残留物等要素（可寄送迈达斯科技换取报酬，如「弧盘」）。
- **侵凌（Encroachment）**：异象对现实普通事物造成的影响；按「反转移定律」，人越接近/越了解异象，越易在肉体与精神上受影响。
- **担保（Guarantee）**：对部分有智慧的异象或其持有者提供的保障，使该异象被允许存在于人类社会；被担保者不必然具有市民身份。
- **异象市民**：以市民身份融入社会、享有并承担权利义务的异象，多数为歧骸，但其他类型（担保过、有自我意识、智力达标的）异象也可。
- **异象猎人（Anomaly Hunter）**：不隶属公权、但从事异象调查/收容/泯除作为营业手段的个人或团体，受公权默认许可；报酬来自公会、民间委托者等。
- **异象委托（Anomaly Commission）**：公开悬赏或指名交给民间异象猎人处理的事件；多由「异象猎人公会」整理发布，也可能包含五大公权外包的委托。
- **异象空间（Anomalous Realm）**：异象以自身能力构建的、无法对应现实坐标的领域（如「月光当铺」「洄廊」）。

## 三、地理 / 城市

### 3.1 海特洛市（Hethereau）——主城 【官（游戏内描述）+ Fandom】
- 异象管理局总局所在城市，「包容、开放且新潮的靓丽大都市」。管理局总部设于此带来高治安水平，并使海特洛在异象/异能管理应用领域处于世界前沿。【Wiki 名词词典】
- 位于一座岛上，与新西里安市相隔；确切现实位置未知。【Fandom】
- 城市多处以现实东京为灵感来源（Fandom 标注）。【社/Fandom】
- 基础设施：有地铁（「城际快线」Intercity Express，但只在本市运行）和公交，**无公共航空与大型海港**。【Fandom】
- 教育：唯一见到的学校为「克莱门学园」（Clement Academy，风格仿日式高中，因异象事件而低调保守）。医疗：「海特洛市立医院」（兼治异象感染者与异能者）。执法：「海特洛公共护盾」（HPS，巡逻车 Novus C2000）+ 异象管理局（管涉异犯罪）。【Fandom】

### 3.3 海特洛市之外的世界 【Fandom + Wiki】
- **新西里安市（New Helios）**：高速发展的新兴开发城市（被诟病「没什么城市文化底蕴」）；Ⅶ 级异象「极漩」降临，几乎摧毁受影响全部区域，留下异化废墟（悬浮建筑、逆生树木、钢筋枝桠）。英文名 New Helios 来自希腊太阳神赫利俄斯。【Wiki 名词词典 + 异象档案 + 萌娘《典故》】
- **向阳岛（Sunward Island）**：海特洛近海岛屿，1.1 版本开放；「一意向阳」度假村实为异象福利院（市政+异象管理局共建）。【Fandom + Wiki】
- **沃伦大陆（Warren Continent）**：1.2 版本开放；异象桌游「九百九十九夜」内的游戏世界（勇者斗赤龙）。【Wiki 剧情页】
- **其他地点异象领域**：月光当铺（Pawn Moonlight）、洄廊（Fogden 雾隐之地/游梦洄廊）等。【Fandom】

## 四、核心概念 / 专有名词词典

### 4.1 玩家角色与伙伴组织
| 术语 | 解释 | 来源 |

### 4.2 异象管理局组织架构 【Wiki + Fandom】
- **J.T.F 联合特遣队（Joint Task Force）**：基层外勤，受过专业训练的普通人；常态化处理辖区内常规异象；兼管维特海默塔维护与监测；与治安所密切合作。
- **C.S.U 收容行动组（Containment Strike Units）**：外勤范围最广的部门；负责一般异象收容/泯除、临时收容异象的看管转移、ETD 行动善后；遵守《新收容安全条例》。主角好友「薄荷（Mint）」属收容二组。

## 五、剧情主线概要 【Wiki 剧情页 https://zh.moegirl.org.cn/异环/剧情 ；Fandom】

### 5.1 玩家身份与开局
玩家扮演失忆的异能者「零」（可选性别），在**新西里安市 Ⅶ 级异象「极漩」灾害**爆发时突然出现，协助异象管理局定位奇点、加速其自然泯除；期间出现无法检测维特海默值的「零号异象」（与主角存在深层关联），随极漩一同泯除。事后主角被白藏发现并控制，送**格赫罗斯岛监狱**观察七周，编号「异能者·零」。获释后与异象管理局局长艾尔菲德签订契约，承诺参与后续「零号异象」收容行动，随即被安置进异象猎人团体「伊波恩古董店」——成为首位「无证上岗」的异象猎人/鉴定师。【官（官网「故事从海特洛市启篇…」）+ Wiki 剧情】

### 5.2 主线目标
1. 作为伊波恩的一员，接取民间异象委托，收容/泯除海特洛市各处异象，探索都市潜藏的超自然谜团。
2. 逐步对抗犯罪组织「红字」：夺回被其掠走的异象（「恒今时」「忒修斯之舵」），查明其首领伊南娜与「游戏」计划。
3. 追溯主角自身身世与「零号异象」之谜（核心悬念，主线持续展开中）。
