# 多模型拆分 · ANE零GPU方案 · 需求文档

> 2026-10-09 · Lead 撰写
> 用户核心诉求：**推理必须不碰 GPU**（游戏需要 100% GPU），24步思维链全保留

---

## 0. 一句话目标

> 把 24步 refiner 拆成多个小 CoreML 模型串联，每个小到跑 CPU/ANE（不碰GPU），
> enc 跑 ANE，总延迟 ≤16ms，GPU 占用 0%。

## 1. 已实测的关键数据（Lead 亲自测）

| 模型 | 节点数 | preferred | 延迟 | 抢GPU? |
|---|---|---|---|---|
| enc（图像编码,有conv） | 170 | ANE 100% | 0.33ms | ❌ 不抢 |
| chunk_4（4步refiner,纯linear） | 70 | CPU | 0.06ms | ❌ 不抢 |
| chunk_8（8步refiner,纯linear） | 149 | CPU | 0.08ms | ❌ 不抢 |
| 融合头（纯linear） | ~50 | CPU | ~0.05ms | ❌ 不抢 |
| ctl整体（24步+MoE+头） | 2440 | GPU | 3.53ms | ✅ 抢15-20% |

**CoreML predict 调用开销**：0.06ms/次（8次串联 = 0.48ms）

## 2. 拆分方案

```
每 tick（30Hz）：
  ① enc: 当前帧 [1,3,180,320] → feat[1,256]        [ANE, 0.33ms]
  ② feat 入特征环形缓冲 → [8,256]                    [零计算]
  ③ 时序+融合: [8,256]+lane+dets+state → fused[1,512] [CPU, ~0.1ms]
  ④ chunk×6: fused → refiner 24步（6块×4步）         [CPU, 6×0.06=0.36ms]
  ⑤ 融合头+三头: fused → steer/throttle/brake+辅助    [CPU, ~0.1ms]
  → 总延迟 ≈ 0.33 + 0.1 + 0.36 + 0.1 = 0.89ms + 调用开销0.48ms ≈ 1.4ms
```
