## 阻塞记录

### 阻塞 ①：引擎 TCC fail-fast（需用户手动授权）

**现象**（AuroraEngine.log 10:34:18）：
```
[ENGINE] 启动 --engine 模式 pid=50716
[ENGINE] TCC 自检 ax=false screen=false
[ENGINE] TCC 权限不足，fail-fast 退出（权限须由父进程链继承）
```

**根因**：run.sh 的 ad-hoc 签名（codesign --sign -）每次重签 CDHash 都不同 →
新二进制的 TCC 授权失效。旧引擎能跑是因为 9/23 签名版本当时被授权过。

**影响**：引擎无法启动 → UI 回退本地模式 → 改动 7（publish memcpy）/10（门禁）/
11（ingest pixelBuffer）的运行时采样无法进行；游戏实测（按键注入/检测框）无法进行。

**需要用户操作**：
系统设置 → 隐私与安全性 → 屏幕录制（勾选 AuroraDrive）；
系统设置 → 隐私与安全性 → 辅助功能（勾选 AuroraDrive）。
授权后重启 AuroraDriveUI，引擎即可 spawn 成功。

**提示词审查时预测过此问题**（"ad-hoc 签名会导致 CDHash 变化 → TCC 权限失效"）✓
