## 用户原话（最高依据）

> 数据都被我删了，之前那些数据只是纯走直线什么都不给的。市面上并没有可用的第三视角自动驾驶模型，必须我们自己后续拿骨干训练，但是必须能输入数据。拍一堆模式去找骨干，必须能输入这些所有数据，**大小不能超过 10MB**，**性能一定要好**。

## 三条硬约束（违反即返工）

| # | 约束 | 说明 |
|---|---|---|
| **1** | **模型总大小 ≤ 10MB** | ⚠️ 不是老的 31MB 上限！参照：现有 M9 = 15MB、game_assist = 7.6MB |
| **2** | **必须能接收全部输入** | 图像（第三视角）+ 车道线掩码（MaskGrid 160×160）+ 检测框（变长 Detection）+ 状态（speed/accel/heading/curvature） |
| **3** | **不要可行驶区域** | 用户明确排除（drivable mask 不进模型） |

## 两条关键事实（引用数据时用实测值）

**训练数据现状（Lead 实测）**：
```
data/raw_clips/ 共 5 个 clip、9.4MB
  clip_20260825_182145: 23 帧
  clip_20260825_182147: 12 帧
  clip_20260922_003025: 2 帧
  clip_20260922_003027: 22 帧
  clip_20260922_003029: 70 帧
controls.csv 字段只有: t_sec,frame,steer,throttle,brake
```
→ **没有 speed/heading/curvature**（尽管 `mono_dataset.py` 声称支持）
→ **旧数据是纯直线**（用户："只走直线什么都不给"）→ 新数据必须有弯道

**模型大小换算**：
- FP16：参数量 × 2 bytes → **10MB ≈ 5M 参数**
- INT8：参数量 × 1 byte → **10MB ≈ 10M 参数**
