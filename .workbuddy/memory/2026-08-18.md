## 朝向缺口已解 + 复刻架构确认（2026-08-19 凌晨，读 angle_predictor.py 源码）
- **用户澄清**：异环小地图**永远朝北**，角色光标(车图标)在小地图上**旋转表示朝向**；MaaNTE 能读光标方向→知道朝向。此说被 `angle_predictor.py` 源码 100% 证实。
- **朝向=纯视觉**：`AnglePredictor` 用 ONNX 关键点模型 `pointer_model.onnx`（资源路径 `model/navi/pointer_model.onnx`），在小地图光标 ROI `[73,60,64,64]` 检测 3 关键点(tip/left/right)→ `angle=atan2(dx,-dy)%360`（dx=tip.x-tail.x, tail=(left+right)/2）。**零内存读、纯截屏识别**。
- **位置=matchTemplate**：`map_locator.py` `MINI_MAP_ROI=(28,15,150,150)` 基于 1280×720 游戏；我们录制 640×360=半分辨率→ROI 同比例 `(14, 7.5, 75, 75)`。模板 = `bigworldmapSecond.png`(11264², 在克隆包里 assets/resource/base/image/map/)。
- **控制=航向误差 PID**（`waypoint_navigator.py`，即 pure-pursuit）：`desired_angle=atan2(dx,-dy)%360`；`angle_delta=(desired-angle+540)%360-180`（最短带符号误差）；`turn=turn_pid.update(angle_delta)`→转向。Waypoints 来自在线地图或自定义路径。
- **⚠️ 复刻资产（已补齐，2026-08-19 凌晨）**：之前 `--depth 1` 浅克隆漏了 git 子模块 `assets/MaaNTEModels`，故 `pointer_model.onnx` 不在包里。已用 `git submodule update --init assets/MaaNTEModels`（ego-browser 真网络）拉下，**模型现在在** `/Users/dupi/Desktop/MaaNTE/assets/MaaNTEModels/navi/pointer_model.onnx`（9.5M）+ `classify/best2.onnx`。**Mac 上 `onnxruntime 1.28.0` 直接可用** → 朝向模型可 Mac 原生跑，不必转 CoreML。
- **pointer_model.onnx 实测 I/O**：input `images`=[1,3,64,64] float（64×64 RGB CHW，/255 归一化）；output `output0`=[1,84,15]。解码(`angle_predictor.py:66-93`)：`confidence=output[:,4]`→argmax 取 best_idx；`best_pred[6:].reshape(3,3)`=3 关键点(tip/left/right,各 x,y,conf)；bbox=best_pred[0:4]；`angle=atan2(dx,-dy)%360`（dx=tip.x-tail.x, tail=(left+right)/2）；`found=max_conf>threshold`(默认0)。
- **ROI 坐标（1280×720 基准）**：`MINI_MAP_ROI=(28,15,150,150)`；其内 `pointer_roi=[73,60,64,64]`。我们录制 640×360=半分辨率→**全 ×0.5**：小地图 `(14,7.5,75,75)`、光标区 `(36.5,30,32,32)`、模型输入仍 resize 到 64×64。
- **Mac 复刻朝向三条路**：①直接用 onnxruntime 跑 `pointer_model.onnx`（最贴合原数，Swift 端用 ORT C API 或 python 桥）；②纯旋转光标模板匹配(无 ML)；③Windows 跑 MaaNTE 借 WebSocket 坐标。位置侧 `bigworldmapSecond.png`(11264²) 在克隆包 `assets/resource/base/image/map/`，matchTemplate 直接复用。
- **结论**：异环「位置+朝向」全可纯视觉从小地图取得，**补上了之前所有死路（小地图/标图/OpenCV/路网网站）的位置源缺口**。封号风险低（视觉不读内存）。
