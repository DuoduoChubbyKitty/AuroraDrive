## DSH 启动崩溃：@zhtx2026/dsh-pdf 社区插件玩废了（已修）
- 现象：DSH 启动报 `Failed to load plugins` / `web boot: 1 entry did not activate` / `dsh-vscode-mode: pending (waiting for service: webUiSettings)`。
- 真因（harness.log）：`dsh: plugin tree failed to load: failed to apply loader entry include (cordis:include): failed to import loader entry pdf (@zhtx2026/dsh-pdf): Cannot find package '@zhtx2026/dsh-pdf'`。整个插件树因这个包找不到而崩溃；`dsh-vscode-mode: pending` 只是级联无害警告，不是元凶。
- 注册位置（不是 launch-root，launch-root 是空的）：`/Users/dupi/Library/Application Support/dsh-desktop/harness/profiles/web/package.json`
  - `dependencies["@zhtx2026/dsh-pdf"]` 和 `dsh.profile.bundles` 里各有一行 `@zhtx2026/dsh-pdf`。
  - 包实体在 `harness/profiles/web/node_modules/@zhtx2026/dsh-pdf/`，但 App 包里的 `cordis-plugin-loader` 按自己的 node_modules 树解析 → 找不到 → 崩溃。
- 修复（彻底删除，用户确认）：①备份 package.json 到 /tmp；②从 dependencies 和 bundles 两处删 `@zhtx2026/dsh-pdf`（注意 bundles 末项去逗号保持 JSON 合法）；③把 node_modules/@zhtx2026/dsh-pdf 目录 `mv` 到 /tmp（可恢复，不用 rm）；④删空父目录 @zhtx2026。
- 重启 DSH（彻底退出重开）harness 即重读 package.json 恢复。备份：`/tmp/dsh-profile-web-package.json.bak`、`/tmp/dsh-pdf-removed-backup`。
- 教训：社区 cordis 插件用 `dsh plugin --profile web add` 装、在 profile package.json 的 `dsh.profile.bundles` 登记；装残/包缺失会整树崩。删插件要同时去 dependencies + bundles + node_modules 三处。
