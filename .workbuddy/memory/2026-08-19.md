## 框架跨平台性核查（用户问"有没有留 Windows 接口"）
- `Package.swift` 仅声明 `platforms: [.macOS(.v14)]`，无 Windows/iOS。
- 全仓 `*.swift` 搜 `#if os(Windows)` / `canImport(WinSDK)` / `targetEnvironment` / `WIN32` → **0 命中**。唯一含 "Windows" 字样的是 `CaptureEngine.swift:195` 的 `SCContentFilter(excludingWindows: [])`（ScreenCaptureKit 参数，与平台无关）。
- 结论：**无任何 Windows 接口 / 跨平台抽象层**。全链路绑死 Apple 专有 API：捕获 ScreenCaptureKit+CGDisplay、注入 CGEvent、推理 CoreML(.mlmodelc)、预处理 CoreImage/vImage、UI SwiftUI。
- 若要上 Windows 需整段重写三层：捕获→DXGI Desktop Duplication、注入→SendInput/ViGEm、推理→ONNX Runtime/DirectML。不是"加接口"能解决的。
