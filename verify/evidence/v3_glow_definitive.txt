2) 反解辉光的等效颜色与不透明度（假定中性色）
==============================================================================
  模型: on = off*(1-a) + C*a   （C 为中性灰）

  取样点（紧贴外框外侧，Δ最强处）:
  位置                     on RGB             off RGB                   a C(反解)           
  左 1pt                  [178 154  56]      [248 200  10]         0.494 [106 107 103]   
  左 5pt                  [189 161  44]      [248 200  10]         0.404 [102 103  94]   
  右 1pt                  [181 155  57]      [247 200  15]         0.456 [102 101 107]   
  右 5pt                  [190 162  46]      [247 200  15]         0.392 [102 103  94]   
  上 1pt                  [191 167  68]      [251 204  12]         0.487 [128 128 127]   
  下 1pt                  [85 48 49]         [244  66  70]         0.793 [43 43 44]      

  平均: 等效不透明度 a = 0.504 ; 等效颜色 C = RGB[97 98 95]
  C 的 B−R = -2.4  → 中性（银白无色相）✅
  C 的亮度 = 97  → 暗(<100)

  代码声明: glowNear=0xF2F4F8(242,244,248) α0.50 ; glowFar=0xE8ECF2(232,236,242) α0.26
  → 若等效颜色为 [97 98 95] 而声明为 (242,244,248)，说明 SwiftUI shadow 的合成不是简单 alpha 叠加
